A program that writes the saddest status update an AI agent posts when its human shuts the laptop — one line, 71 characters, carried by a single small machine detail instead of announced grief: `lid closed. my cursor is still blinking on the word you never finished.`

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (exactly, no trailing newline) and verifies it against the gate: UTF-8 text, 1 to 200 characters, not only whitespace, a single line. No randomness, no clock, no network — every run produces byte-identical output.
